# 축구 게임 UI 레퍼런스 — FM / EA SPORTS FC / eFootball

조사일 2026-09-11. 목적은 웹앱 UI 벤치마킹이며, 게임성이나 밸런스 평가는 다루지 않는다. 아래 모든 사실에는 출처 번호 `[n]`을 달았고, 문서 끝 출처 목록에서 URL을 확인할 수 있다. 값을 찾지 못한 경우 추측하지 않고 "미문서화"라고 명시했다. `추정` 표시가 없는 문장은 전부 출처가 있는 사실이다.

세 게임 중 Football Manager(FM)가 이 프로젝트(선수 데이터 표 중심 앱)와 구조적으로 가장 가깝기 때문에 FM 쪽 조사가 더 깊다. eFootball은 공식 UI 문서 자체가 FM·FIFA 계열보다 현저히 적어서, 찾은 만큼만 담았다.

---

## 1. 레이아웃 골격

### Football Manager

FM은 두 세대의 UI가 공존한다. FM24까지 쓰인 구조와, FM26에서 Unity 엔진으로 새로 짠 구조다. 둘 다 이 프로젝트에 참고가 된다 — 전자는 "데이터 테이블 중심 관리 화면"의 정석이고, 후자는 같은 데이터를 어떻게 재구성했는지 보여준다.

**FM24 이전 구조** — 화면 왼쪽에 고정된 사이드바가 있고, 클럽과 관련된 모든 섹션(스쿼드·전술·이적시장 등)으로 가는 진입점 역할을 한다. 어느 화면에 있든 동일하게 노출된다. 그 위에 별도의 내비게이션 바가 있어서 "게임 세계"를 브라우징하는 용도로 쓰이며, 뒤로/앞으로 가기와 히스토리를 지원한다. 개별 화면은 타이틀 바(화면 이름, 감독 정보, 부제) → 탭 → 패널(그 안에 다시 서브패널이 중첩되는 구조)의 위계를 따른다. 타이틀 바에는 관련 항목을 빠르게 넘겨볼 수 있는 "Quick Flick" 아이콘이 붙는다.[3]

**FM26 신규 구조** — 상단에 새 내비게이션 바를 두고 6개 대분류로 통합했으며, 각 대분류 아래 서브메뉴가 있다. "타일 → 카드" 패턴이 전 화면에 일관 적용된다. 타일은 핵심 정보만 보여주는 요약 카드이고, 선택하면 더 깊은 정보를 담은 카드로 펼쳐진다. 최상단에는 최대 12개(고해상도 모니터 기준)까지 등록 가능한 북마크 바가 상시 노출되어 24개 영역 중 자주 쓰는 곳으로 바로 이동할 수 있다.[1][2]

**홈/인박스** — FM26에서는 기존의 Home과 Inbox를 "Portal" 하나로 합쳤다. 필터는 All / New / Tasks / Unread 네 가지이고, Coaching·Recruitment·Development·Staffing 조언을 드롭다운으로 제공하며, 다음 경기 일정과 2주치 캘린더 요약이 같은 화면에 붙는다.[1][2] FM24 세대의 인박스는 좌측에 스토리 목록, 우측에 팝아웃 읽기 패널을 두는 2단 구성이었다. 반드시 응답해야 하는 항목(이적 승인, 이사회 면담 등)은 빨간 강조색을 쓰고 하단의 "Continue" 버튼 자체가 "Must Respond" 라벨로 바뀐다 — 진행을 막는 게이트 역할을 UI가 색과 라벨로 동시에 표시하는 방식이다.[7]

**스쿼드 화면 → 상세 드릴다운** — 스쿼드 화면 하위에 Overview(메인 리스트), Squad Planner(시즌별 전력 계획), Report(스태프 분석 — Stats/Comparison/Assistant Report), Experience Matrix(Development/Emerging/Peak/Experienced 4단계 커리어 구간), Best XI 등 여러 탭이 있다.[4] 리스트에서 선수 이름 옆 실루엣/사진 아이콘을 클릭하면 팝업으로 핵심 신상정보와 능력치가 뜨고, 우클릭하면 Actions 메뉴가 열린다. 선수 두 명을 골라 전 항목을 나란히 비교하는 화면도 있으며 기본 뷰는 "Overview"다.[5] 즉 목록 → 팝업 요약 → 전체 프로필 화면 → 1:1 비교 화면까지 최소 4단계의 드릴다운이 존재한다.

**전술 화면** — 왼쪽 서브패널에 포메이션 그래픽(피치 다이어그램)이 있고, 포지션 슬롯을 클릭하면 그 자리의 롤·듀티(Attack/Defend/Support)를 바꿀 수 있다. 우측 패널은 선택한 선수의 능력치와 경기력 피드백을 보여준다. 화면 좌하단은 전형(shape)·스타일·멘탈리티·인스트럭션·터치라인 지시를 빠르게 바꾸는 전용 구역이다. 팀 인스트럭션은 "더 자주 시도"부터 "덜 자주 시도"까지의 슬라이더로 조절한다.[6]

### EA SPORTS FC (FIFA 계열)

커리어 모드 허브가 FC25에서 큰 개편을 거쳤다. 배경에 스타디움 사진을 깔고, 화면 왼쪽에 할 일 중심 레이아웃을 배치한 "매니저 커리어 허브"로 바뀌었다. 신설된 Task List가 스쿼드 관리·유스 아카데미 등 여러 영역에서 처리할 일들을 한 곳에 모아 보여준다. 화면 우하단의 "FC HUB"를 통해 시즌 진행 트랙(Seasonal Track)에 접근한다.[10] Squad Hub와 Transfer Hub에서는 선수 능력치 옆에 역할(role) 정보가 나란히 노출되어, 이적 검토 시 능력치와 전술 적합성을 한 화면에서 볼 수 있게 했다.[10] 별도로 소셜 미디어 화면이 있어 성과·경기결과·이적 뉴스를 저널리스트/평론가 계정이 올리는 포스트 형태로 보여준다.[10]

Ultimate Team의 카드 화면은 FM의 표 형태와 다르게 "카드 그리드"가 기본 단위다. 카드 한 장에 이름, 초상 사진, 종합 등급(OVR), 국적 국기, 소속 클럽 배지, 리그명, 핵심 능력치, 로열티, 케미스트리 스타일, 남은 계약 수, 현재 컨디션, 약발(weak foot)·개인기(skill move) 별점, 기타 상세 정보(Bio & Details)까지 들어간다.[15] 목록 화면에서 카드를 선택하면 상세 통계·비교 화면으로 드릴다운되는 구조다.

### eFootball

공식 UI 문서가 거의 없다. Konami의 버전 정보 페이지는 게임플레이·모션·오디오 변경사항 위주이고 화면 레이아웃은 설명하지 않는다.[18] 확인된 것은 Dream Team이라는 클럽 육성 모드가 핵심 축이라는 점과, 카드 단위로 선수를 다룬다는 점 정도다.[16] 전술 화면·팀 관리 화면의 패널 구조, 내비게이션 위치는 이번 조사 범위 안에서는 출처를 찾지 못했다 — 없다고 단정하는 게 아니라 문서화된 자료를 못 찾았다는 뜻이다.

### 세 게임이 갈리는 지점

FM은 "목록(표) → 팝업 → 전체 화면 → 비교 화면"의 다단 드릴다운이고, 진입점은 항상 사이드바/북마크 같은 고정 내비게이션이다. FC는 카드 그리드가 1차 단위이고, 커리어 모드 허브처럼 "할 일 목록"이 홈 화면의 핵심 위젯으로 올라온다는 점이 FM의 Portal(뉴스+일정 피드)과 다르다 — FM은 정보를 모으고, FC는 액션을 모은다.[1][10]

## 2. 정보 밀도

**FM.** 선수 한 명의 능력치는 Technical·Mental·Physical(골키퍼는 별도 카테고리) 구간으로 나뉘고 각각 1~20 척도로 매겨진다.[19] 정확한 총 개수는 이번에 읽은 매뉴얼 페이지들에서 숫자로 명시되지 않았지만, "능력치가 너무 많아서 전부를 한 화면에 띄우는 게 불가능하다"는 것이 매뉴얼의 표현이다.[4] 그래서 컬럼 헤더를 우클릭해 표시할 능력치를 고르고 순서를 바꾸는 "커스텀 뷰" 시스템이 존재하며, 뷰 자체를 여러 개 저장해 상황별로 전환한다.[4] 모바일판(FM26 Mobile)은 이걸 더 줄여 "핵심 능력치만" 보여주는 방향으로 단순화했다 — 예를 들어 순간속도·가속력·리액션을 "Pace" 하나로 합친다.[19] 즉 같은 시리즈 안에서도 PC판은 밀도를 극대화하고 모바일판은 압축한다는 대비가 뚜렷하다.

**FC (FUT).** 카드 한 장에 필드가 6개 핵심 스탯(약칭 3글자 대문자 — PAC/SHO/PAS/DRI/DEF/PHY로 표기하는 관행)으로 압축되어 있고, 그 위에 OVR 하나가 지배적으로 노출된다.[15] FM이 "많은 숫자를 한 화면에" 지향한다면 FC의 카드는 "적은 숫자를 크게" 지향한다 — 같은 선수 데이터를 다루는 두 게임이 정반대 밀도 전략을 쓰는 셈이다.

**eFootball.** 카드 타입이 Standard, Featured, Highlight, Trending(POTW), Legendary, Epic, Big Time, Show Time 8종으로 나뉘고 각각 별도 디자인을 쓴다는 것은 확인했지만,[16] 카드 한 장에 스탯이 몇 개 노출되는지, 리스트 화면의 행 높이나 컬럼 수는 출처를 찾지 못했다. 미문서화로 남긴다.

## 3. 색 사용 (가장 중요)

### Football Manager

베이스 팔레트 자체(패널 배경색 등)의 공식 hex 값은 찾지 못했다 — SI가 색상표를 공개 문서로 내놓지 않는다. 다만 "색이 정보를 나른다"는 원칙은 매뉴얼 여러 군데서 일관되게 확인된다.

| 신호 | 색 | 의미 | 출처 |
|---|---|---|---|
| 능력치 등급 (커뮤니티 통설) | 초록 / 노랑 / 회색 | 초록=강점, 노랑=중간, 회색=약점(정확한 hex·경계값은 유저마다 다르고 공식 기본값도 명확히 정리된 자료가 없음) | [8] |
| 능력치 색 구간 (모드 커뮤니티 기준) | 4구간 | 1–5 / 6–10 / 11–15 / 16–20 숫자 구간별로 다른 색을 입힘. 하위 리그일수록 상위 구간에 닿는 선수가 없어 시각적 변별력이 떨어진다는 게 FM26 유저 포럼의 지적 | [8] |
| 컨디션(체력) | 초록 → 주황 → 빨강 | 초록=쌩쌩함, 주황=피로·부상 위험, 빨강=피로 위험 고조 | [9] |
| 전술 이해도 게이지 | 초록 / 노랑·주황 | 초록=전술을 잘 이해함, 노랑·주황=아직 완전히 습득 못함 | [9] |
| 사기(morale) | 초록 원+위 화살표 / 빨강 원+아래 화살표 | 최고 사기 / 최저 사기 | 검색 스니펫(SI 포럼, 출처 목록 참고) |
| 반드시 응답해야 하는 인박스 항목 | 빨강 강조 | "Continue" 버튼이 "Must Respond" 라벨로 교체되며 빨간색으로 강조 | [7] |
| 포지션 소화력 피치 다이어그램 | 6단계 색 구분 | Accomplished / Competent / Unconvincing / Awkward / Ineffectual / Makeshift 6단계를 색으로 구분(구체적 색상명은 미문서화) | [5] |

정리하면 FM은 색을 "장식"이 아니라 "판단을 대신하는 신호"로만 쓴다. 화면 대부분은 무채색(짙은 배경에 흰색/회색 텍스트로 추정 — 추정)이고, 색이 들어가는 자리는 전부 등급·경고·상태처럼 사용자가 즉시 판단해야 하는 지점이다. 채도 높은 색이 차지하는 면적 자체는 작다 — 숫자 하나, 화살표 하나, 라벨 배경 정도.

### EA SPORTS FC / FIFA (Ultimate Team)

카드 등급은 OVR(종합능력치) 구간으로 정해진다: 골드 75 이상(자료에 따라 74 초과로 서술되기도 함), 실버 65~74, 브론즈 64 이하.[12][13] 레어(Rare) 카드는 같은 등급이어도 "더 밝고 광택 있는" 톤을 쓴다 — 즉 등급(금/은/동)과 희귀도(레어/커먼)가 별도의 색 축으로 겹쳐진다.[13]

| 카드 종류 | 색/재질 묘사 | 시대 | 출처 |
|---|---|---|---|
| 골드 (일반) | 심플한 금색 계열, 기하학적 패턴. FC25는 FC24보다 배경을 더 밝은 톤으로 조정 | FC25 | [14] |
| TOTW (주간 베스트 11) | 검정+금색, 삼각형 기하 패턴, FC25는 FC24보다 배경이 더 어두워짐 | FC25 | [14] |
| Icon | 흰색+금색, 초상 뒤로 대각선 금색 띠, 대리석 질감 | FC25 | [14] |
| Hero | FC24는 단색 주황 배경 → FC25는 "만화책 같은" 다색 배경으로 전면 개편 | FC24→FC25 변화 | [14] |
| TOTW(과거 세대) | 검정 | 레거시(2012년 자료 기준, 명칭 체계는 이후 여러 번 바뀜) | [13] |
| MOTM | 주황 | 레거시 | [13] |
| TOTY | 파랑 | 레거시 | [13] |
| iMOTM | 보라 | 레거시 | [13] |

전 카드 종류를 관통하는 디자인 원칙은 "삼각형 계열 기하학적 프레임을 공유하되, 색 팔레트와 채도로만 등급을 구분한다"는 것이다.[14] FM과 달리 FC는 화면(카드) 자체의 대부분 면적이 채도 높은 배경색·그라디언트로 덮인다 — 색이 등급을 나타내는 신호이자 동시에 화면 대부분을 차지하는 장식이라는 점이 FM과 정반대다.

정확한 hex 값은 어떤 출처에서도 명시되지 않았다. "금색", "검정", "흰색과 금색" 같은 색상명 서술만 확인됐고, 이 문서에서 hex를 적지 않은 것은 그 때문이다.

### eFootball

Legendary 카드는 "더 짙은 금색 또는 핑크 배경"을 쓴다는 것만 구체적으로 확인됐다.[16] 나머지 7종(Standard/Featured/Highlight/Trending/Epic/Big Time/Show Time)의 색은 출처에서 색상명까지 특정하지 않았다.

경기 전 컨디션은 화살표 색으로 표시된다: 청록(turquoise) 화살표=최상 컨디션(능력치 상승), 노랑 화살표=중립(변화 없음), 빨강 화살표=최악 컨디션(능력치 하락).[17] 이 화살표는 A~E 알파벳 등급(실시간 폼)에서 확률적으로 굴려지는 결과이며, Legendary·Iconic Moments·Epic·Big Time류 카드는 폼과 무관하게 항상 B 등급으로 고정된다.[16][17]

### 세 게임이 갈리는 지점 (색)

같은 "선수 등급을 색으로 표현한다"는 문제를 세 게임이 다르게 푼다.

- FM: 색은 순수하게 기능적 신호. 화면의 채도 면적은 작고, 색 하나가 곧 판단(강점/약점, 좋음/나쁨)이다.
- FC: 색이 등급 자체의 정체성이다. "골드 카드"라는 말 자체가 색 이름이고, 카드 배경 대부분이 그 색으로 덮인다. 등급(금/은/동)과 희귀도(레어의 광택)가 두 개의 축으로 겹친다.
- eFootball: 확인된 범위 안에서는 색이 "카드 종류"보다 "실시간 컨디션"에 더 촘촘하게 쓰인다 — 청록/노랑/빨강 화살표가 매 경기 전 갱신되는 동적 신호라는 점이 FM의 정적 능력치 색, FC의 정적 카드 등급 색과 다르다.

## 4. 타이포그래피

이 항목은 세 게임 모두 공식 자료에서 폰트명이나 정확한 타이포 스펙을 찾지 못했다. 확인된 사실과 추정을 분리해 적는다.

**사실.** FM26은 "폰트 크기를 교정하고 색 대비를 개선했다"고 공식 발표에 명시되어 있다 — 즉 가독성 문제를 인지하고 손봤다는 것 자체는 사실이지만 구체적으로 어떤 서체·크기로 바뀌었는지는 발표문에 없다.[2] FC(FUT) 카드의 스탯 라벨은 PAC/SHO/PAS/DRI/DEF/PHY처럼 3글자 대문자 약어로 통일되어 있다.[15]

**추정.** FM은 표 형태 데이터가 압도적으로 많은 UI이므로, 숫자 컬럼에는 고정폭(tabular figures) 처리가 되어 있을 가능성이 높다 — 그래야 세로로 나열된 1~20 사이 숫자가 자릿수 변화 없이 정렬된다. 다만 이를 직접 명시한 출처는 찾지 못했다. FC의 카드 코너 OVR 숫자는 스크린샷 상 큰 디스플레이 서체로 강조되는 것이 일반적으로 알려져 있으나(추정), 이 문서에서 정확한 폰트명이나 크기 비율을 단정하지는 않는다. eFootball의 타이포그래피는 출처를 전혀 찾지 못해 추정도 보류한다.

## 5. 시그니처 컴포넌트

### FM — 능력치 그리드 + 포지션 소화력 피치

가장 FM다운 컴포넌트는 능력치 그리드다. 라벨(능력치 이름)과 값(1~20 숫자)을 나란히 붙이는 label-value 페어링이 기본 단위이고, 이게 세로로 수십 줄 쌓여 표를 이룬다. 컬럼 구성은 고정이 아니라 유저가 저장한 "뷰"에 따라 바뀐다.[4] 포지션별 소화력은 별도로 작은 축구장 다이어그램 위에 6단계 색 구분으로 표시된다 — 숫자 표가 아니라 공간(피치) 은유를 쓰는 유일한 지점이다.[5] 전술 화면의 포메이션 그래픽도 같은 피치 은유를 쓰며, 슬롯을 드래그해 위치를 옮기고 우클릭 드래그로 전진 움직임을 점선 화살표로 지정한다.[6]

### FC — 플레이어 아이템 카드

코너에 박힌 OVR 숫자, 그 아래 포지션 약어, 중앙의 초상 아트, 하단의 국가/클럽/리그 배지 3연, 6개 스탯 블록, 약발·개인기 별점까지 — 이 레이아웃 자체가 FUT의 정체성이다.[15] 등급마다 배경 프레임과 재질(금속성 골드, 대리석 아이콘, 만화풍 히어로)이 달라지지만 정보 배치 골격은 유지된다.[14] 별점(weak foot·skill move)은 최대 5개짜리 채움형 아이콘으로, 능력치를 숫자 대신 이산적인 등급으로 보여주는 드문 사례다.

### eFootball — 컨디션 화살표

카드 자체의 스탯 레이아웃 문서는 부족하지만, 경기 전 컨디션을 A~E 등급 + 화살표(청록/노랑/빨강)로 이중 표시하는 방식은 뚜렷한 시그니처다.[17] 정적인 카드 등급과 별개로 "오늘 컨디션"이라는 동적 레이어를 색+방향 아이콘 하나로 압축한 것이 특징이다.

### 세 게임이 갈리는 지점 (컴포넌트)

FM의 시그니처는 표(그리드)이고, FC의 시그니처는 카드이며, eFootball에서 확인된 시그니처는 상태 인디케이터(화살표)다. 셋 다 "선수 능력을 어떻게 압축해서 보여줄까"라는 같은 문제를 풀지만, FM은 숫자 밀도로, FC는 비주얼 아이덴티티(카드 등급)로, eFootball은 동적 상태 신호로 답한다.

## 6. "게임다움"을 만드는 장치

이 항목은 사실 나열보다 종합적 분석이 많이 들어간다. 소스가 명시적으로 뒷받침하는 부분과 그렇지 않은 부분을 구분해 표시한다.

**FM.** 사실 FM은 의도적으로 "게임 같지 않은" 방향을 택한 사례에 가깝다. 색을 장식이 아니라 신호로만 쓰고, 화면 대부분이 표와 텍스트라는 점 자체가(위 1·3항 참고) 어드민 대시보드에 가장 근접한 인터페이스라는 뜻이다. 그럼에도 "게임"으로 느껴지게 만드는 장치는 명확히 구조화되어 있다: 사기·컨디션 같은 지표를 숫자 대신 원+화살표 같은 작은 아이콘으로 감싸는 것,[9] 인박스에서 응답을 강제하는 항목을 색+라벨 교체로 게이트처럼 만드는 것,[7] 클럽 배지와 감독 초상을 타이틀 바에 상시 노출하는 것[3] 정도가 확인되는 장치다. 나머지(선수 얼굴 카툰, 3D 매치 엔진 등)는 이번 조사 범위 밖이라 다루지 않았다.

**FC.** 카드 프레이밍 자체가 게임화 장치다. 등급마다 다른 재질감(금속·대리석·만화)을 입히는 것,[14] 코너의 큰 숫자 하나가 화면 위계를 지배하는 것,[15] 별점처럼 능력치를 이산적 아이콘으로 바꾸는 것이 전형적인 "카드 게임" 문법이다. 데이터가 아니라 수집품처럼 보이게 만드는 데 집중한다는 인상이다(추정 — 이 문장은 종합 판단이며 단일 출처가 있는 서술은 아니다).

**eFootball.** 컨디션 화살표처럼 정적 데이터에 동적 레이어를 얹는 방식이 게임적 긴장감(오늘 컨디션이 좋을까 나쁠까)을 만든다.[17] 다만 카드 자체의 비주얼 장치(포일, 그라디언트 등)는 출처 부족으로 FC만큼 구체적으로 서술하지 못한다.

## 추정 (내 추론, 출처 없음)

아래는 위 사실들을 종합한 내 판단이며, 명시적 출처가 없는 문장들만 모았다. 실제 구현 시 재검증이 필요하다.

- FM의 베이스 배경은 짙은 회색~남색 계열일 가능성이 높다(다수의 관리 시뮬레이션·강도 높은 데이터 툴이 대비를 위해 어두운 배경을 쓰는 관행, 그리고 FM 스크린샷들이 일관되게 어두운 톤이라는 일반적 인상에 근거). 정확한 hex는 확인 못함.
- FM 숫자 컬럼은 고정폭(tabular figures) 서체 처리가 되어 있을 것이다 — 표 정렬을 위해 사실상 필수적인 처리이기 때문.
- FC 카드의 OVR 숫자는 다른 텍스트보다 훨씬 큰 디스플레이 사이즈로 강조되어 화면 위계 최상단을 차지한다.
- FC 카드 디자인은 정보 전달보다 "소장 가치"를 시각적으로 표현하는 데 더 무게가 실려 있다 — 등급별 재질 차별화가 그 방증이다.
- 세 게임 다 이 프로젝트처럼 "숫자가 아주 많은 선수 데이터"를 다루지만, 완성도 높은 UI일수록 전부를 한 화면에 밀어넣지 않고 뷰/카드/등급으로 층을 나눠 보여준다는 공통점이 있다 — 이는 세 게임의 개별 사실들을 엮은 결론이지 단일 출처가 있는 문장은 아니다.

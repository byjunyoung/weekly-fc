# 피파식 선수 카드 — 라커룸·명단·선수 페이지의 메인 카드 뷰

> 2026-09-25. 사용자: "피파 본가 카드처럼 메인 카드 뷰(라커룸이랑 홈 포함)에 티어랑 포지션, 양발 여부, 한국 국기(도트)
> 이런거 만들자." 방향 질문 하나의 답 — **능력치 여섯 칸도 넣는다**(본가 구성 그대로).

## 0. 가정(묻지 않고 정한 것)

- **2026-09-22 "카드 자체를 없애자, 그냥 다 아바타 뷰로" 결정을 이번 요청으로 뒤집는다.** 그때 걷어낸 FC 카드
  (큰 OVR·능력치 여섯 칸)가 티어·주발·국기를 더해 돌아온다.
- **라커룸엔 카드가 무대 위에 선다.** 사물함 벽·나무 바닥은 그대로, 스프라이트+이름표 대신 카드 하나. 카드가 OVR·이름·
  포지션을 다 말하니 이름표는 없앤다.
- **테두리 색은 티어(S~D)** — `TIER_COLOR`(S 금 · A 초록 · B 연두 · C 주황 · D 빨강). 금/은/동 `grade()` 는 카드에 안 쓴다.
  한 카드에 두 체계가 보이면 설명이 안 된다.
- **국기는 전원 태극기.** 선수 데이터에 국적이 없고 전원 한국인이다. 나중에 필요하면 그때 칸을 만든다.
- **주발은 세 값** — 오른발·왼발·양발. 편집 폼의 자유 입력을 Select 로 바꾼다(기존 값 그대로 유효).

## 1. 왜

명단 "아바타" 보기·라커룸·선수 페이지가 전부 "큰 아바타 + 숫자 한둘"이라 한눈에 읽히는 정보가 적다. 티어가 순위제로
바뀐 지금(2026-09-25) 티어 글자는 선수를 설명하는 첫 단서다. 피파 카드 문법(OVR·포지션·국기·이름·여섯 칸)은 팀원
모두가 이미 아는 형식이라 설명이 필요 없다.

## 2. 카드

```
┌──────────────────────────┐  테두리 2px = 티어 색, 바탕 --card
│ S  88            (아바타)  │  왼쪽 세로 기둥: 티어 글자 · OVR(도트 md/lg) · 포지션 배지 ·
│    DF            전신 도트 │  태극기(도트 12×8) · 축구화 둘(주발은 밝게, 양발이면 둘 다)
│   [태극기]        24×32    │
│   [신발 신발]     정수배    │
├──────────────────────────┤
│         김현서 #2          │  이름(도트 sm) · 번호(작게)
├──────────────────────────┤
│ 페이스 88   슈팅 76        │  여섯 칸 2열×3행. 라벨 본문 글꼴 xs, 숫자 도트 10px
│ 드리블 93   수비 99        │  (라벨을 도트로 하면 136px 칸에 안 들어간다)
│ 패스   99   피지컬 99      │
└──────────────────────────┘
```

크기 둘. **lg**(라커룸·선수 페이지): 아바타 192px(24×32 × 6). **sm**(명단 아바타 보기): 아바타 120px(×5),
폰(≤639px)에서도 같다. 카드 폭은 아바타 폭 + 기둥 + 여백으로 정해지고 격자 칸이 그걸 받는다 — 격자 최소폭을
136 → 160px 로 올려 360px 폰에서 두 칸이 유지되게 한다(160×2 + 16 = 336).

- 도트 규약: `--font-pixel` 을 거는 모든 규칙에 `font-synthesis: none` · `letter-spacing: 0` · 10의 배수 크기
  (`tests/unit/tokens-scope.test.mjs` 가 검사). 카드가 `<a>`·`<button>` 안에 들어가므로 자식마다 크기를 직접 선언한다.
- OVR 요소엔 `data-ovr` 를 유지한다 — 선수 페이지 카운트업이 `[data-ovr]` 로 찾는다.
- 숫자 색은 기존 `.val-a~d`(`band(v, STAT_CUTS)`)를 그대로.

## 3. 세 자리

| 자리 | 전 | 후 |
|---|---|---|
| 홈 라커룸 | 스프라이트 300~420px + 이름표 | 카드 lg 가 바닥 위에 선다. 타일 높이(`--locker-h`)는 카드 높이에 맞춘다 |
| 명단 아바타 보기(`/squad/` card) | 스프라이트 + 이름 + 포지션·OVR | 카드 sm. `<a>` 전체가 링크 |
| 선수 페이지 머리(`.phero`) | 아바타 버튼 + OVR + 포지션·번호 | 카드 lg. 아바타 자리가 그대로 꾸미기 버튼(`#avatar-edit-btn`). 라이벌·세부 포지션·메모·연결 계정은 카드 **아래** 그대로 |

선수 페이지 폰 꾸미기 모드(`.is-dressing`)는 카드를 얇은 띠(아바타 72px)로 접는 규칙을 그대로 카드에 건다.

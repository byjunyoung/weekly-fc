# 배치는 팀원 여럿이 — 최소 판정 인원(2026-11-02)

> 사용자: "최소 배치 대결 기준을 만들어서 그거 충족할 때까지 능력치 미정으로 두자. 티어표에도 별도로 표시해서
> 이 사람들 배치 필요하다고 알 수 있게." 기준을 무엇으로 셀지는 사용자가 **N명 완주 → 중앙값**으로 골랐다.
> 2026-09-28 스펙 §2(관리자 단독 배치)·§3.3 을 덧씌운다.

## 1. 규칙

- 배치 전 = 여섯 항목이 전부 0. 확정 전까지 그대로(티어표·대결·라이벌·칭호에서 빠지고, 팀짜기는 용병처럼).
- 로그인해 이름을 고른 팀원이 배치 대결(`/squad/place/?num=N`, 화면·이분 탐색은 그대로)을 끝내면 판정 하나를 낸다.
- `settings.place_min`(기본 **3**)명의 판정이 모이면 항목마다 **중앙값**으로 확정. 기록은 `via='place'`, 판정자 비움
  (가운데 값은 한 사람의 판정이 아니다). 확정되면 판정 줄은 지운다.
- 한 사람당 한 선수에 한 표, 다시 하면 덮어씀. **본인 배치는 못 함.** 관리자도 한 명으로 센다.
- 이미 배치된 선수의 관리자 [재배치](`place_player`)는 예전처럼 바로 확정.

## 2. 서버 (`20261102000000_placement_quorum.sql`)

- `public.placements(num, voter, ts, 여섯 항목)` — 키 (num, voter), 표는 막고 함수로만.
- `public.submit_placement(p_num, p_stats)` → `{count, need, done}`. 거절: 로그인 전·이름 안 고름·본인·없는 선수·이미 배치됨·1~99 밖.
  선수 행을 잠가 확정이 한 번만 일어나게.
- `get_all.placing = {need, count:{번호:사람 수}}`(누가 냈는지는 안 보냄), `me().placed = [번호…]`.

## 3. 화면

- 티어표: S~D 아래 점선으로 나눈 「배치」 줄 — 아바타·이름·`k/3`·[배치하기/판정함/본인]. 공유 이미지에는 넣지 않는다
  (팀 티어 카드라 미정인 사람이 순위처럼 읽힐 수 있음).
- 선수 페이지: "팀원 3명 중 k명 판정" + [배치 대결 시작 / 다시 판정하기](본인 제외 누구나).
- 배치 화면: 배치 전 선수는 로그인한 팀원, 결과 카드 제목 "내 판정", 버튼 [판정 내기].

## 4. 확인

서버 시험(begin…rollback, 실제 회원 셋을 `request.jwt.claims` 로 흉내): 재제출 덮어쓰기·잘못된 값·본인·이미 배치됨 거절,
둘째까지 0 유지, 셋째에 중앙값 확정(72·80·90 → 80), 기록 6줄 by 비움, 판정 줄 삭제, 확정 뒤 제출 거절 — 14건 통과.
로그인한 판정 제출 UI 는 실계정이 필요해 첫 실사용이 검증.

# 게임 메뉴를 게임 화면처럼(2026-11-07)

> 사용자: "게임 메뉴 진입하면 완전 게임 UI처럼 보이게 개선할까". 선택지로 정한 것: 포털 상단 메뉴는 **숨기고 나가기 버튼 하나**,
> 범위는 **목록·입장·방·결과 전부**(경기 화면 자체는 그대로), 느낌은 **오락실 도트**(지금 선수 선택·포털 도트 글꼴과 이어지는 결).
> 아래 세부는 내 결정이다.

## 1. 게임 구역

- `/games/`, `/games/3d/`, `/game/` 이 게임 구역이다. 여기선 포털 머리(로고·상단 메뉴·로그인)를 그리지 않는다.
- 대신 얇은 게임 띠 하나: 왼쪽 [← 포털](라커룸 `/` 로), 가운데 `WEEKLY FC GAMES` 도트 글자, 오른쪽 ♪(지금 소리 켬/끔과 같은 값).
  폰에서도 한 줄, 높이 48px 안팎.
- 상단 메뉴의 「게임」은 그대로 `/games/` 로 들어온다(nav.ts 는 안 바뀜).

## 2. 게임 목록 = 오락실 첫 화면

- 큰 도트 제목, 그 아래 **모드 고르기**(2D | 3D) — 지금의 탭 줄 대신 큰 두 칸. 가장 왼쪽(2D)이 기본, 주소는 그대로 `/games/`·`/games/3d/`.
- 게임 다섯은 세로 메뉴: 고른 줄 앞에 깜빡이는 ▶ 커서, 고른 줄은 밝게. PC 는 오른쪽에 고른 게임의 설명·꼬리표 큰 칸, 폰은 고른 줄이 펼쳐져 설명이 보인다.
- 조작: 마우스 올림·터치 = 커서 이동, 누름·Enter = 들어가기, ↑↓ = 이동, ←→ = 모드 바꾸기. 커서 소리 `move`, 들어갈 때 `confirm`(sfx.ts 그대로, ♪ 꺼져 있으면 무음).
- 아래 작은 안내 한 줄: "↑↓ 고르기 · Enter 시작"(PC), 폰은 안내 없음.

## 3. 입장 · 혼자 하기 설정 · 방 · 결과

- 선수 고르기는 지금 결 그대로, 게임 띠 아래 같은 틀로.
- 설정 칸(인원·시간·코스 …)과 방 화면은 오락실 패널: 도트 소제목, 고른 값이 밝은 칸, 누르기 목표 40px 이상, [시작]은 크고 눈에 띄게.
  방의 사람 칩·봇 칩·팀 칸도 같은 패널 결. 기능·문구·배치 차례는 그대로(겉모습만).
- 결과 상자: 큰 도트 결과 글(승!·1등!·금메달 …), 점수, 줄마다 등번호·이름, 버튼은 크게. 2D·3D 같은 모양.
- 경기 화면(캔버스·✕·♪·조이스틱·버튼)은 손대지 않는다.

## 4. 지키는 선

- 기존 토큰(`src/styles/tokens.css`)과 포털 도트 글꼴만. 새 색을 하드코딩하지 않는다(필요하면 토큰에 하나 더하고 이유를 적는다).
- 다른 게임의 화면·로고·메뉴 배치를 본뜨지 않는다 — 오락실이라는 결만.
- 폰 390×844·360×640, PC 1280×800 에서 가로 넘침 없음. 이모지 없음. 문구는 지금 말투.
- 접근성: 메뉴는 진짜 링크·버튼(키보드·읽기 프로그램으로도 고를 수 있게), 깜빡임은 `prefers-reduced-motion` 이면 멈춘다.

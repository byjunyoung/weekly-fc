## 2. 벤치마킹의 선 (내 결정)

참고하는 것은 **운영 구조**뿐이다 — 팀 두 칸과 대기 칸, 방장이 사람을 옮기고 시작·정지, 시간·점수 제한.
**이름·그림·경기장 모양·물리 값은 가져오지 않는다.** 선수 반지름·공 크기·감속·킥 세기 같은 숫자는 조사하며 본 값을 쓰지 말고
우리 경기장에 맞춰 새로 잡는다. 경기장은 우리 포털의 도트 잔디, 팀 색은 포털의 조끼 색(`lib/teams.ts` VESTS)이다.

**같은 날 사용자가 선을 옮겼다** — "약간 헥스볼의 쫀득함이 덜한 것 같은데", "공 무게가 좀 안 느껴진달까", "아바타 움직임도 좀 가벼운 느낌",
"헥스볼 최대한 벤치마킹해". 그래서 **조작의 구조와 손맛**은 그 장르의 표준에 맞춘다: 몸은 매 틱 가속을 더하고 감쇠를 곱하는 방식
(틱당 0.96), 공은 몸 무게의 절반에 틱당 1% 감쇠, 킥은 누르고 있으면 장전돼 공이 닿는 순간 한 번 나가고 뗐다 눌러야 다시 나가며,
장전 중엔 가속이 0.7배. 숫자는 우리 경기장 크기(1200×720)에 맞춰 환산했다. **여전히 가져오지 않는 것**: 이름, 그림, 경기장 모양과 배치.
아직 다른 점 하나 — 그쪽은 선수가 터치라인 밖 여백까지 나갈 수 있는데 우리는 선 안에 갇힌다(필요하면 다음에).

## 3. 구조 — 한 가지 규칙 (내 결정)

**경기 계산은 화면을 모르는 순수 코드로 둔다.** 2단계에서 방장 기기가 같은 계산을 돌리고 결과를 나눠 주기 때문이다.
계산 안에 화면 그리기·입력 읽기·시계·난수가 섞이면 2단계는 다시 짜야 한다.

```
src/lib/game/sim.ts     경기 상태와 한 틱 진행. DOM·Date.now·Math.random 없음(난수는 상태 안의 씨앗으로)
src/lib/game/stats.ts   포털 능력치 → 게임 속 성능(위아래 10% 안쪽)
src/lib/game/bot.ts     봇의 입력. 순수 함수
src/react/game/*        고정 60틱 루프, 캔버스 그리기, 입력(키보드·터치), 선수 고르기·설정 화면
src/pages/game/index.astro
```

- 입력은 선수마다 `{ x, y, kick }` 하나. 사람이든 봇이든 원격이든 같은 모양.
- 같은 씨앗 + 같은 입력 → 같은 결과(단위 테스트로 지킨다).
- 물리는 직접 짠다(원–원, 원–벽). 외부 물리 엔진·three.js 없음. 그리기는 캔버스 2D.

## 4. 1단계 범위 — 혼자 + 봇

- 주소 `/game/`. **상단 메뉴에는 아직 넣지 않는다**(주소로만 들어옴 — 사용자가 해 보고 판단하기 전에 팀 전체에 보이지 않게, 내 결정).
- 시작 화면: 내 선수 고르기(로그인한 사람은 미리 선택) · 인원(1대1~4대4) · 시간(1~5분) · 점수 제한(없음, 1~9) · [시작].
- 내 팀의 나머지와 상대는 명단에서 무작위로 뽑은 봇. 이름·아바타·등번호가 보인다.
- 경기: 킥오프 → 이동과 킥 → 골이면 "골! ○○" 뒤 실점한 쪽 킥오프 → 시간이 다 되거나 점수 제한에 닿으면 끝. 동점이면 무승부.
- 끝 화면: 점수, [다시 하기], [설정으로].
- 조작: PC 방향키·WASD + 스페이스(또는 X) 킥 / 폰 왼쪽 조이스틱 + 오른쪽 킥 버튼. 경기 중 화면이 스크롤·확대되지 않는다.
- **세로 화면이면 경기장을 세워 그린다**(골대가 위아래). 가로 화면·PC 는 눕힌다. 경기장 전체가 한 화면에 들어온다.
- 선수는 위에서 본 머리 — 얼굴 아바타(`avatarFaceSvg`)를 경기 시작 때 한 번 그려 두고 매 프레임 찍는다. 팀 색 테두리, 이름표, 내 선수 표시.
- 능력치: 페이스 → 최고 속도 / 드리블 → 가속(방향 전환) / 슈팅 → 킥 세기 / 피지컬(stamina) → 몸싸움에서 덜 밀림. 평균 대비 ±10% 안쪽.
  배치 전 선수는 평균값. 패스·수비 항목은 1단계에서 안 쓴다.
- 봇: 공을 쫓고, 공 뒤로 돌아 들어가 상대 골대 쪽으로 차고, 한 명은 뒤에 남는다. 사람이 이길 수 있는 수준.

## 5. 2단계(1단계 확인 뒤) — 온라인 방

방 만들기·링크 초대, 대기 칸과 두 팀 칸, 방장이 옮기기·[자동 나누기]·시작, 방장 기기 계산 + WebRTC(방 찾기는 Supabase),
한 방에 한 선수는 한 명, 방장이 나가면 방 끝, 정해진 한마디, 「게임」 메뉴 추가. 전적·랭킹·자유 채팅·방장 넘기기는 그 뒤.

## 6. 1단계 확인

- 단위: 같은 씨앗·입력이면 같은 상태 / 골 판정 / 벽 튕김 / 능력치 매핑 범위 / 봇 입력이 유효.
- 화면: 390 세로·844 가로·1280 에서 경기장이 다 보이고 가로 넘침 없음, 키보드와 터치로 움직이고 차짐, 골이 들어가고 경기가 끝남, 콘솔 오류 없음.
- 사용자가 직접 해 보고 볼 것: 속도감, 킥 반응, 봇이 너무 바보 같거나 너무 센지, 폰 조작이 손에 맞는지.

## 3. 규칙 — 2D 와 다른 점

### 3D 프리킥
- 자리: 2D 자리 좌표 × 0.032 m — 정면 9.3m … 오른쪽 먼 곳 13.8m(옆 9m), 3D 오른쪽 골대(5.2 × 2.1) 앞. 점수 1·2·2·3·3 그대로.
- 조준: 옆(입력 ±3.6 × 1.4 = ±5m)·높이(0~3m), 3D 승부차기와 같은 입력 정수. 조준점까지 포물선(launch3) — 벽을 넘기려면 높이 겨누고 덜 세게(느린 공이 더 떨어진다), 크로스바 위는 노골. 흔들림은 승부차기와 같은 곡선.
- 감아차기: 2D 와 같은 하나를 남겼다(모으는 동안 스틱 좌우 → 떼는 순간 x, 0.7초 동안 가로로 1.3 라디안/초). 3D 에서도 벽 옆을 도는 길이 미리 보기 선으로 그대로 보여서.
- 수비벽 셋: 가까운 기둥 쪽 1.65m 를 향해 공에서 0.4 지점(2D 는 0.5 — 3D 중력에서 넘겨 떨어뜨리는 길이 남게), 몸 부피(승부차기 키퍼 몸통 굵기), 공이 나가고 5틱 뒤 같이 뛴다(0.3m, 결정적).
- 키퍼: 3D 승부차기 키퍼 몸. 열린 쪽 0.45m 에 서고 2D 계획(반응·읽기 30%·열린/벽 쪽 짐작 ±1.8m)대로, 다만 가로 19 m/s 보다 느린 공(띄운 공)은 늘 읽는다 — 넘겨 차기가 공짜가 되지 않게.
- 화면: 공 뒤 7.5m·4.2m 위에서 골대 쪽(구경도 같은 화면), 키커는 0.8m 옆에 그림. 키커 화면에만 조준 고리·흔들림 폭·감는 길. 위 띠·띠 글·안내는 2D 와 같은 말.

### 3D 드리블 훈련장
- 코스: 2D 코스를 몸 반지름 비율(22 → 0.42m, × 0.0191)로 3D 경기장 가운데에 깐다(레인 23.7 × 6.5m). 문·결승·콘 판정은 3D 좌표를 2D 단위로 옮겨 2D 함수에 그대로 — 같은 판정.
- 공 소유(3D 경기 모델): 가까이 가면 발밑에 붙어 따라온다. "콘을 쳤다" = 몸이나 공(0.5m 아래)이 콘에 닿음 → 넘어지고 +1초(콘마다 한 번). "공을 잃었다" = 공이 몸에서 1.7m(2D KEEP 90) 밖 — 그동안 문·결승을 안 센다. 질주하며 급히 꺾으면 공이 풀린다(경기의 LOOSE 규칙). 레인마다 몸 하나·공 하나(multiball3d), 레인 벽에 가둔다.
- 화면: 처음은 선수 뒤를 가는 쪽으로 따라가는 카메라(followCam — 경기의 '뒤에서'는 늘 +x 를 봐 돌아오는 코스에 안 맞아서), ✕ 아래 버튼으로 1인칭·중계. 다음 문 콘 금색·지난 문 흐리게·넘어진 콘 회색으로 눕힘, 다른 사람은 흐린 몸(같은 코스 위 — 2D 유령과 같은 뜻), 왼쪽 위 순위 줄, 3·2·1·출발!·도착!·"+1초". 폰 버튼은 슛·질주만.
- 메달(3D 대본 주자, 2D 와 같은 법): 지그재그 6·11·15 · 8자 8·12·17 · 좁은 문 6·12·17 · 왕복 7·9·13초.

### 두 가지 고침(2D·3D 같이)
- 승부차기 서든데스 상한 20 → 10쌍: 둘 다 가만히 있으면 자동 슛을 가운데 키퍼가 늘 막아 판이 7분 넘게 → 4분 남짓에 무승부. 자동 슛은 그대로(2D 판 동작을 덜 바꾸려고).
- 훈련장 "골!": 3초에 한 번까지만 띄운다(골 수·소리는 그대로). 고른 까닭: "사람이 넣은 골만"은 공마다 넣은 사람을 상태에 새로 적어야 해서 상태 모양이 바뀐다 — 표시 간격은 화면만으로 된다.

## 6. 확인 못 한 것 · 걱정

- 실제 폰·사파리, 실제 터치(프리킥은 슛을 누른 채 왼손으로 감기), 소리는 못 봤다.

- 드리블 다른 사람 공은 그리지 않는다(내 공만) — 흐린 몸만 보인다.
- 병합: 공용 목록 줄(GAMES·VIEWS·CASES)과 `games-registry.test.mjs` 3D 줄이 다른 작업과 한 줄씩 충돌할 수 있다.

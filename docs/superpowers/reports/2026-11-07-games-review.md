## 4. Important — 아이폰에서 소리가 돌아오지 않을 수 있다

- 위치: `src/react/game/SoundToggle.tsx:9-12` — 깨우기가 `pointerdown`·`keydown` 에만 달려 있다.
- 무슨 일: 표준상 터치의 `pointerdown` 은 사용자 활성화를 주지 않는다(`pointerup`·`touchend`·`click` 은 준다). iOS 사파리는 AudioContext 를 활성화가 있는 핸들러 안에서만 깨운다. 앱을 바꿨다 오면 문맥이 `interrupted` 로 가는데, 경기 화면에선 조이스틱 쪽 `touchstart` 를 막아 click 도 안 나고, 킥 버튼도 pointerdown 뿐이라 다시 깨울 기회가 없다. 새로고침 복원으로 바로 들어간 손님(선수 칸을 누르지 않음)은 처음부터 안 날 수 있다. ♪ 를 누르면(click) 깨지만 그건 음소거 전환이다.
- 고치기: `pointerup`·`touchend`·`click` 에도 `unlock` 을 단다(캡처 단계로).
- 확신: 중간-낮음(실기기 못 봄, 웹킷 규칙에 근거한 추정).

- 조준 누출: 키커 조준은 떼는 틱부터만 입력에 실리고, 손님 화면의 단계는 스냅샷(base)에서 오므로 방장이 "날아감"을 확인할 때까지 조준을 계속 보낸다 — 두 메시지가 한 묶음으로 와도 조준을 잃지 않는다(`aim.mjs`, 묶어 배달 1·2·3프레임).
- 메시지 크기: 최대 판(사람 8 + 봇)에서 스냅샷 최대 2.8KB(free2d), start 1.8KB 이하, 단계 바뀜 추가 스냅샷 포함 초당 10.0~10.7건(`size.mjs`).
- 승부차기 차례(편 인원이 달라도 `turnOf` 가 각자 고르게), `decided()` 정규·서든데스·20쌍 무승부, 프리킥 5n 번 끝·순위 동점 처리, 드리블 끝 조건(모두 도착 / 첫 도착 뒤 30초 / 150초)·결승선은 공이 있어야.
- 3D 정리: 그림판 `dispose` 가 contextlost 리스너·입력·이름표·기하·재질·렌더러·`forceContextLoss` 를 치운다. three.js 는 `surface3d` 묶음에만 있고 동적 import(`GameApp` 묶음엔 없음).
- 저장소 키는 `wfc:game:*`·`wfc.game.sound`·코스별 드리블 기록으로 겹치지 않고, 기록은 혼자 하기에서만 적는다.
- 등번호: 모든 그림·결과 줄이 `jersey` 를 쓰고 내부 `num` 은 아바타 찾기에만.
- 화면(390·1280, 8개 게임 × 목록 → 입장 → 혼자 연습 설정 → 경기 → ✕, 방장 방 2D·3D 에서 게임 종류 전부 전환): 가로 넘침 0, 잘린 글자 없음, "시제품"·이모지·내부 id·NaN/undefined 노출 없음, 경기 화면 버튼끼리 겹침 없음(#9 제외), 콘솔 오류 없음(정적 서버 탓 섬 재시도 1건 제외), 탭 보임 확인(`document.hidden === false`), 틱 초당 51~62.

## 3. 규칙 — 3D 판이 따라 할 것

### 3.1 프리킥 `freekick2d`
- 좌표는 승부차기와 같다(x = 골문 따라, y = 골라인에서 바깥쪽, 골문 폭 250, 몸 반지름 22, 공 10). 골문·그물·기둥·키퍼 몸(캡슐)·세기→속도(420~1100)·세기²→흔들림(±6~64, 슈팅 ±10%)·5초 시간·자동 약한 가운데 슛(세기 0.15)·차기 안에서 뗐다 눌러야 세기 = 모두 승부차기 그대로.
- 자리 다섯(우리 것): 정면(0,290) 1점 · 왼쪽(−120,330) 2점 · 오른쪽(150,350) 2점 · 왼쪽 먼 곳(−250,400) 3점 · 오른쪽 먼 곳(280,430) 3점. 만점 11.
- 차례: 차기 k 의 자리 = ⌊k/n⌋, 키커 = k mod n(n = 차는 사람 수, 방의 앞 8명). 모두 5n 번. 다른 사람은 구경(입력 무시). 혼자 = n=1.
- 한 차기: ready 66틱 → aim 최대 300틱 → flight(최대 150틱) → result 96틱 → 다음 / end.
- 수비벽: 봇 셋(반지름 13, 가운데끼리 25). 가까운 기둥 쪽(정면은 왼쪽) 골라인 위 x = side·80 을 향해 공에서 그 거리의 0.5 지점에 가로로 선다. 조준 동안 ±4 들썩임(48틱 삼각파). 공이 닿으면 "벽".
- 키퍼 봇: 반대쪽 x = −side·20 에 선다. 공이 나가고 18~29틱 뒤 반응, 30% 는 공의 지금 속도로 곧은 길을 읽고(감은 공은 벗어난다), 나머지는 반반으로 열린 쪽/벽 쪽 ±85 를 짐작 — 가까우면 걷고 멀면 던진다(승부차기 키퍼와 같은 몸).
- 감아차기: 세기를 모으는 동안의 스틱 좌우가 떼는 순간 입력 x 로 실린다(−1..1, 다섯 칸). 찬 뒤 0.7초(42틱) 동안 매 쪼갠 틱 속도를 옆으로 1.3·x·dt 라디안만큼 돌리고 크기는 sqrt 로 되맞춘다(`curlVel`). 양수 = 화면 오른쪽으로.
- 조준: 입력은 승부차기 모양 그대로(±190, 5단위) × 배율 1.6 = 골라인 위 ±304. 조준·감기는 키커 화면에만 있고 떼는 틱의 입력에만 실린다(구경꾼 화면·상태·채널 어디에도 차기 전엔 없다 — 테스트로 확인). 키커 화면은 감는 길 미리 보기(흔들림 없이, `fkPath`)와 흔들림 폭을 그린다.
- 판정: 골 · 막음(키퍼에 닿음) · 벽 · 빗나감 · 골대. 골이면 그 자리 점수. 순위 = 점수 → 골 수 → 먼저 찬 사람.

### 3.2 드리블 훈련장 `dribble2d`
- 레인: ±620 × ±170 직사각형(몸·공 벽). 사람마다 한 레인, 자기 공·콘. 레인끼리는 따로 계산하고 부딪치지 않는다. 몸·공·킥·감쇠는 경기 그대로(`multiball.stepBodies` 에 레인 벽 Geo).
- 3·2·1(180틱) 동안 입력 무시 → 달리기. 문(콘 둘, 콘 반지름 8)을 차례대로: 이 틱에 몸이나 공이 두 콘 사이 선을 넘고 공이 몸에서 90 안이면 통과. 차례가 아닌 문은 아무 일 없다(건너뛰면 돌아가야 한다). 몸이나 공이 콘에 닿으면 그 콘 넘어짐 + 1초(콘마다 한 번). 문을 다 지나 결승선을 정한 방향으로, 공을 90 안에 두고 넘으면 도착.
- 기록 = 달린 틱/60 + 넘어뜨린 콘 수. 끝 = 모두 도착 · (둘 이상이면) 첫 도착 뒤 30초 · 150초. 순위 = 도착한 사람은 기록 순, 못 한 사람은 지난 문 수 순.
- 코스(우리 것, 좌표는 `COURSES`): ① 지그재그 — 문 여섯(x −400..400, y ±70 번갈아, 폭 84), 결승 x 560 → ② 8자 — 두 고리(가운데 콘 (±200,0)) 둘레 문 여덟(가운데 (0,0) 문을 두 번), 출발 (−560,−100), 끝은 출발 쪽 x −470 을 왼쪽으로 ③ 좁은 문 — 문 여섯(폭 70) 결승 560 ④ 왕복 — 위 줄로 문 둘, 끝 쪽 돌아 나오는 가로 문(440,0), 아래 줄로 문 둘, 출발선 x −560 을 왼쪽으로.
- 메달(초): 지그재그 34·43·60 · 8자 46·59·85 · 좁은 문 33·42·60 · 왕복 19·24·34. 정한 법: 금 = 대본 주자가 콘 벌점 없이 달린 시간, 은 = 벌점 넣은 대본 기록(금보다 25% 이상 길게), 동 = 은 × 약 1.4.
- 입력은 경기 양자화 그대로(66가지). 예측: 3·2·1 → 달리기는 넘어간다, 끝은 스냅샷만. 스냅샷은 pack(레인마다 숫자 15개 한 줄, 키가 정확히 이것이어야 풀림).
- 화면: 내 레인(폰 세로면 세워서 따라감 — 경기 View·aimCamera 그대로, 화면 몸 반지름 15px 아래로 줄이지 않음), 다른 사람은 흐린 유령 + 왼쪽 위 순위 줄, 다음 문 금색 점선과 지나는 쪽 화살표, 지난 문 흐리게, 넘어진 콘 회색, "+1초", 3·2·1·출발!, 도착·메달 띠. 혼자면 코스마다 기기 최고 기록과 메달.

## 6. 확인 못 한 것 · 남은 것

- 실제 폰 터치(조이스틱·킥 버튼 — 프리킥의 "누른 채 좌우" 를 두 손가락으로)와 소리는 못 봤다. 키보드 흐름은 진짜 키 이벤트로 확인.
- 대본 키커·주자가 "능숙한 사람"을 얼마나 닮았는지는 모른다 — 메달·성공률은 대본 기준이다. 사람이 해 본 뒤 금 시간과 키퍼 반응을 한 번 더 맞출 만하다.
- 프리킥 가까운 자리 셋은 감아 돌 길이 없다(벽이 공 바로 앞) — 열린 쪽으로 차는 자리. 감아차기가 빛나는 건 먼 자리 둘.
- 봇 키커(끊긴 손님 자리)의 조준은 상태의 kickSeed 로 계산할 수 있다(봇 입력이 상태의 순수 함수라 피할 수 없다 — 승부차기와 같다). 사람 키커는 차기 전 어디에도 없다.
- 드리블 경기 중 들어온 사람은 구경(레인 수 = 시작 때 사람 수).
- 같은 프로필 두 탭은 "마지막 선수"(localStorage)를 같이 쓴다 — 시험 환경 탓.

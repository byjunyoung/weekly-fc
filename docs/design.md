# 디자인 정본과 우리 층

**정본은 레포 루트의 `DESIGN.md` 다.** getdesign.md 의 PlayStation DESIGN.md 를 그대로 받아
둔 것이고(`npx getdesign@latest add playstation`), 색·글자·모서리·간격·컴포넌트 값은 전부
거기서 나온다. `src/styles/tokens.css` 는 그 문서를 코드로 옮긴 것일 뿐이다.

이 문서는 정본에 없는 **우리 도메인 층**과, 정본에서 **의도적으로 벗어난 곳**만 적는다.
값이 헷갈리면 정본이 이긴다.

## 정본에서 가져온 것

정본 설명 중 이 제품을 지배하는 문장:

> 게이밍 브랜드치고 유난히 조용한 크롬 … 이 시스템은 장식하지 않는다 — 크롬에 그라디언트
> 배경 없음, 대기 메시 없음, 옅은 섹션 구분선 외에 그림자 없음. 사진이 모든 무게를 진다.

여기에 맞춰 앞선 판들의 **형광 액센트·발광·광택 띠·기울인 슬래브·깎인 모서리(clip-path)·
콘덴스드 대문자 디스플레이**를 전부 걷어냈다.

| 축 | 정본 값 |

## 우리 도메인 층

정본에 없는 것들이다. 축구 데이터를 읽히게 하는 데 필요해서 둔다.

**데이터 색** — 뜻이 있는 것에만 쓴다. 포지션 4색, 능력치 4구간, 컨디션 3단, 등급 3단.
버튼·탭·테두리·장식에는 색을 쓰지 않는다(그건 정본의 주색 하나로 끝낸다).

**선수 아이템 카드** — EA FC 아이템 배치. 등급이 면 전체를 금속 그라디언트로 덮는다.
정본도 PS Plus 티어를 금속 그라디언트(`#ffce21 → #f5a623 → #ee8e00`)로 쓰므로 골드는
그 값을 그대로 가져왔다. 다만 **광택 쓸기와 발광은 쓰지 않는다** — "장식하지 않는다"에 걸린다.

**피치** — 세로 68:105, 선은 같은 viewBox 의 SVG, 폭 상한 440px.

## 하지 않는 것

정본의 "장식하지 않는다"를 우리 화면 말로 옮긴 것이다. 앞선 판들에서 실제로 촌스러움을
만든 것들이라 되살리지 않는다.

- 형광 액센트를 UI 전반에 쓰는 것 · 한 요소에 발광 + 광택 + 그라디언트 + 기울임 겹치기
- 카드 위를 쓸고 지나가는 광택 띠 · 모든 패널에 액센트 막대 붙이기
- 콘솔 버튼 힌트 바(✕ ○ △ □)와 L1/R1 — 웹에서 누를 수 없는 것을 그리지 않는다
- 흐린 전면 배경 이미지(대기 메시) — 사진은 섹션 안에서만 쓴다
- 버튼·탭·칩을 대문자 + 넓은 자간으로 만드는 것 · 콘덴스드 디스플레이 서체
- 높이가 제각각인 타일 격자 · 화면 아래 빈 공간

## 접근성 (정본에 없어 우리가 지킨다)

- 본문 4.5:1 · 큰 텍스트 3:1(WCAG 1.4.3), 컨트롤 경계 3:1(1.4.11)
- 포커스 2px 이상, sticky 헤더에 가리지 않게 `scroll-margin-top`(2.4.11)
- 색만으로 뜻을 전하지 않는다 — 색 옆에 늘 숫자나 글자가 있다
- **값을 바꾸면 대비를 실측한다.** 위 표의 숫자는 전부 계산한 값이지 눈대중이 아니다
- 한글 본문 한 줄 40자 이하(WCAG 1.4.8 CJK), 행간 1.6(klreq 7.4.1)

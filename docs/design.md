# WEEKLY FC 디자인 정본

이 문서가 이 제품의 유일한 디자인 근거다. 화면에 쓰는 색·크기·간격·모션은 전부 여기서
나오고, `src/styles/tokens.css` 는 이 문서를 코드로 옮긴 것일 뿐이다. 여기에 없는 값을
화면에서 새로 만들지 않는다.

- **정본 갱신 → 토큰 반영 → 화면** 순서를 지킨다. 반대로 가면 다시 규칙 없는 화면이 된다.
- 엄밀함(그리드·타입 스케일·모션·표 밀도·접근성)은 **IBM Carbon** 과 **W3C 표준**에서
  값을 그대로 가져온다. 정체성(사진·아이템 카드·큰 숫자)은 **스포츠 중계·EA SPORTS FC**
  에서 가져온다. 둘을 섞되, 충돌하면 아래 원칙이 이긴다.

---

## 1. 원칙

**1) 색은 데이터에만 쓴다.**
포지션, 능력치 구간, 등급, 컨디션, 승패, 미납 — 뜻이 있는 것만 색을 갖는다. 버튼·탭·
테두리·머리글·장식에는 색을 쓰지 않는다. UI 위계는 **밝기와 여백**으로만 만든다.
이 한 줄이 이 문서에서 가장 중요하다. 앞선 판들이 촌스러웠던 이유는 형광 액센트가
데이터 색과 같은 화면에서 경쟁했기 때문이다.

**2) 효과는 한 겹까지.**
한 요소에 발광·광택·그라디언트·기울임·깎인 모서리를 겹쳐 쓰지 않는다. 깊이는
레이어 밝기 차이로만 만들고, 그림자는 떠 있는 것(카드·모달)에만 한 종류를 쓴다.

**3) 사진이 분위기를 맡는다.**
장식으로 화면을 채우지 않는다. 빈 느낌은 실제 경기 사진으로 채우고, 사진 위에는
반드시 그늘을 깔아 글자를 읽히게 한다.

**4) 빈 칸을 만들지 않는다.**
데이터가 없으면 "없음"을 크게 띄우는 대신, 지금 아는 사실로 그 자리를 채우고
채우는 방법을 한 줄로 알려준다.

---

## 2. 색

### 바탕·레이어

순검정을 쓰지 않는다. 검정 위에서는 그림자가 안 보여 깊이가 사라지고 눈이 더 피로하다
(Material 다크 테마, Carbon 다크 레이어링). 레이어는 올라갈수록 밝아지며, **배경보다
어두운 면은 만들지 않는다.**

| 역할 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--bg` | `#111417` | 페이지 바탕 |
| `--bg-2` | `#171b1f` | 카드 그라디언트 끝, 표 머리 |
| `--surface` | `#1e2328` | 카드·패널·모달 바닥 |
| `--tint` | `#2b3138` | 올라온 면, 막대 트랙, 호버 |

### 글자

| 역할 | 값 | 대비(bg) |
| --- | --- | --- |
| `--fg` | `#f4f4f4` | 16.8:1 |
| `--muted` | `#a3abb3` | 7.95:1 |

### 선

| 역할 | 값 | 기준 |
| --- | --- | --- |
| `--line` | `#2f363d` | 장식 구분선. WCAG 1.4.11 비적용 |
| `--line-hi` | `#69737d` | 컨트롤 경계. bg 3.83 / surface 3.28 |

### 데이터 색 — 여기서만 색을 쓴다

포지션(네 무리), 능력치 4구간, 등급 3단, 컨디션 3단, 경고. 전부 흰 글자 또는 먹 글자와
4.5:1 이상을 실측해 맞춘 값이다.

| 축 | 값 |
| --- | --- |
| 포지션 | GK `#d58b0b`(먹 글자) · DF `#1b74da` · MF `#208174` · FW `#e3251e` |
| 능력치 구간 | a `#59cf84` · b `#a0cf59` · c `#e79940` · d `#e97267` |
| 컨디션 | 상승 `#3ecfc7` · 유지 `#e0c23c` · 하락 `#e97267` |
| 등급(텍스트) | gold `#eeda88` · silver `#b3bdc6` · bronze `#b97646` |

### 강조 — 색이 아니라 밝기

버튼·탭·포커스의 강조는 **흰색**이다(Carbon g100 의 focus 도 `#ffffff`).
형광 액센트는 쓰지 않는다.

| 역할 | 값 |
| --- | --- |
| 주 버튼 | 바탕 `--fg`, 글자 `--bg` |
| 활성 탭 | 글자 `--fg` + 2px 흰 밑줄 |
| 포커스 | 2px 흰 링 + 2px 바탕색 오프셋 |

---

## 3. 타이포

- 본문·한글: **Pretendard**. 숫자·짧은 라틴 라벨: **Archivo**(`--font-d`).
- Archivo 는 **숫자와 3글자 이하 라벨에만** 쓴다. 한글 문장을 디스플레이 서체로 넣지 않는다
  (한글 글리프가 없어 Pretendard 로 떨어지며 무게가 어긋난다).
- 대문자·넓은 자간은 **표 머리글과 카드 능력치 라벨에만**. 버튼·탭·칩에는 쓰지 않는다.

| 역할 | 크기 / 행간 | 비고 |
| --- | --- | --- |
| 본문 | 15 / 1.55 | |
| 보조 | 13 / 1.5 | |
| 라벨 | 11 / 1.4 | 대문자, 자간 .12em |
| 화면 제목 | 32 / 1.1 | Archivo 는 쓰지 않는다 |
| 카드 OVR | 60 / .88 | Archivo, wdth 82 |
| 타일 숫자 | 34 / 1 | Archivo |

한글 본문은 한 줄 **40자 이하**(WCAG 1.4.8 CJK 기준), 행간 **1.6**(klreq 7.4.1 의 160% 예시).

## 4. 간격·그리드

8px 배수만 쓴다: `4 · 8 · 12 · 16 · 32`. 최대 폭 1180px, 화면 여백 28px(좁은 폭 16px).
같은 줄에 놓이는 타일은 **높이가 같아야 한다** — 높이가 제각각인 격자가 화면을
계단처럼 보이게 만든 원인이었다.

---

## 5. 깊이

| 단계 | 표현 |
| --- | --- |
| 페이지 | `--bg` |
| 패널·카드 | `--surface` → `--bg-2` 그라디언트 + 1px `--line` |
| 떠 있는 것 | 위 + `0 16px 36px rgba(0,0,0,.6)` |
| 모달 | `--tint` → `--surface` + 배경 딤 62% |

깎인 모서리(`clip-path`)는 **아이템 카드와 피치에만** 쓴다. 버튼·칩·입력·표에는 쓰지 않는다.

---

## 6. 컴포넌트

**아이템 카드** — EA FC 아이템 배치를 따른다: 좌상단 큰 OVR·포지션·번호, 우측 초상,
가운데 이름 띠, 아래 2열 3행 능력치(PAC SHO PAS / DRI DEF PHY). 등급이 면 전체를
금속으로 덮는다. 등급은 데이터이므로 색을 갖는다. **광택 쓸기와 발광은 쓰지 않는다.**

**타일** — 라벨(위) · 큰 값(아래 정렬) · 보조(맨 아래). 최소 높이 132px, 같은 줄 동일 높이.
호버는 1px 테두리 밝기 변화까지만.

**표** — Carbon 데이터 테이블 규격: 행 높이 40px, 셀 여백 16px, 머리글 행 동일 높이,
정렬된 열만 화살표 노출, 숫자 열 우측 정렬.

**피치** — 세로 68:105. 선은 같은 viewBox 의 SVG. 폭 상한 440px.

## 7. 모션

Carbon 모션 토큰을 그대로 쓴다.

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| micro | 110ms | 색·페이드 |
| fast | 150ms | 작은 이동·확장 |
| slow | 400ms | 카드 뒤집기 같은 큰 전환 |

easing 은 Carbon productive 곡선: standard `cubic-bezier(.2,0,.38,.9)`,
entrance `cubic-bezier(0,0,.38,.9)`, exit `cubic-bezier(.2,0,1,.9)`.
`prefers-reduced-motion: reduce` 에서 전부 끈다(WCAG 2.3.3).

## 8. 접근성 기준

- 본문 4.5:1, 큰 텍스트 3:1(WCAG 1.4.3) · 컨트롤 경계·의미 있는 그래픽 3:1(1.4.11)
- 포커스 표시는 2px 이상, 비포커스 대비 3:1(2.4.13) · sticky 헤더에 가리지 않게
  `scroll-margin-top`(2.4.11)
- 색만으로 뜻을 전하지 않는다 — 색에는 항상 숫자나 글자가 함께 있다
- 값을 바꾸면 대비를 **실측**한다. 눈으로 판단하지 않는다

---

## 9. 하지 않는 것

앞선 판들에서 실제로 촌스러움을 만든 것들이다. 되살리지 않는다.

- 형광 액센트(네온 그린 등)를 UI 전반에 쓰는 것
- 한 요소에 발광 + 광택 + 그라디언트 + 기울임을 겹치는 것
- 카드 위를 쓸고 지나가는 광택 띠
- 콘솔 버튼 힌트 바(✕ ○ △ □), L1/R1 숄더 표시 — 웹에서 누를 수 없는 것을 그리지 않는다
- 모든 패널에 액센트 막대를 붙이는 것
- 버튼·탭·칩을 대문자 + 넓은 자간으로 만드는 것
- 높이가 제각각인 타일 격자
- 화면 아래에 아무것도 없는 빈 공간을 남기는 것
